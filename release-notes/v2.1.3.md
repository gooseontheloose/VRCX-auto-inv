## PAW Inviter - VRCX 2.1.3

### Fixed
- **Username Checker** missed names held by old or visitor accounts, because VRChat ranks those low in search. It now checks the top 10 search results instead of only the first.

### From upstream VRCX
- No upstream changes in this release.

---

### Install
Download and run **`PAWInviter_2.1.3_Setup.exe`**

Handles VC++ Redistributable, registry, and Start Menu shortcuts automatically.
Upgrading from a previous version? The installer replaces it silently and relaunches.

### Portable
Extract **`PAWInviter_2.1.3.zip`** anywhere and run `VRCX.exe`.
